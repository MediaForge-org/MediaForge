# ADR-0018 – Audiobook Chapters Independent from Physical Files

Status: accepted

Kapitel gehören zur Audiobook Edition und sind unabhängig von der Anzahl physischer Files. Bei einer großen Datei kann MediaForge offizielle Kapitel recherchieren/verifizieren und der Benutzer wählt anschließend zwischen logisch-only, CUE/Sidecar oder physischen Chapter Files. Original Keep ist Default.
