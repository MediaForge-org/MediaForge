# ADR-0015 – Human-readable Media Routes

Status: accepted

Sichtbare MediaForge-Seiten verwenden sprechende Slug-Routen. Kanonische Identität bleibt ULID-basiert. Slug-Historie verhindert tote Bookmarks.

Adult verwendet standardmäßig `/adult/...`; optionaler Strict-Private-URL-Modus verwendet neutralere/opake IDs.

Stream-Sessions bleiben opaque und kurzlebig.
