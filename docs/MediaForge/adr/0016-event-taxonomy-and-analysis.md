# ADR-0016 – Event/Attribute/Evidence Model for Content Analysis

Status: accepted for data-model preparation

Zeitbezogene Analyse wird als `Event + start/end + modality + base tag + attributes + evidence + confidence + verification + model version` modelliert.

Hierarchische Taxonomie wird gegenüber flachen zusammengesetzten Tags bevorzugt. Negative/checked-absent Ergebnisse sind ausdrückbar. Analyse-Coverage und Event-Confidence sind getrennte Konzepte.
