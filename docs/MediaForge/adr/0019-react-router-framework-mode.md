# ADR-0019 — React Router Framework Mode statt Next.js als Web-Standard

Entscheidung: MediaForge nutzt React 19 + TypeScript + React Router Framework Mode + Vite. Laravel bleibt der einzige Full-Stack-Control-Plane-Server. Inertia wird migriert/entfernt; Next.js wird nicht als zusätzliche Server-Schicht eingeführt.
